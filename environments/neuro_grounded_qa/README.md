# neuro-grounded-qa

**Status: in progress.** This package is a placeholder while the environment is built. It contains a stub taskset with one placeholder task, no tools and no rewards. Don't use it for evaluation yet.

A [Verifiers](https://github.com/PrimeIntellect-ai/verifiers) (v1) environment for answering Alzheimer's-centered biomedical questions only from evidence retrieved from a PrimeKG subgraph, and abstaining when the evidence can't support an answer.

No graph data ships in this package. Source repository: https://github.com/kaitlinmoore/primekg-neuro-grounded-qa
